Train:
python train.py

Main knobs:
--timesteps: total env steps
--episodes: total episodes
--max-episode-steps: timeout per episode
--vector-envs: rollout parallelism on CPU
--batch-size: GPU memory/load
--gradient-steps: GPU compute per rollout step
--replay-buffer-size: RAM usage
--target-entropy: policy randomness target
--progress-every-seconds: live status print interval

Stop/resume:
Ctrl+C saves artifacts_reward_v3/checkpoints/sac_final.pt
python train.py --resume artifacts_reward_v3/checkpoints/sac_ep2100.pt
python train.py --auto-resume

Simulate:
python simulate.py
Eval outputs are named with the checkpoint stem and never overwrite older runs.
